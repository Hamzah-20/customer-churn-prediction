# Research Question
## "To what extent can an interpretable machine learning pipeline, 
##    combining feature engineering with SHAP explanations, 
##    improve the accuracy and actionability of customer churn prediction 
##    in the telecommunications sector?"

### Sub-questions:
1. Which features (tenure, contract type, monthly charges) are the strongest predictors of churn?
2. Can SHAP analysis provide actionable insights for retention marketing?
3. How does a tree-based ensemble (Random Forest) compare to a linear baseline (Logistic Regression) in terms of recall for minority class?
